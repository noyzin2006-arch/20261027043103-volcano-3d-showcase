# 火山｜地球内部的力量 — 3D 交互科学图鉴

一个**完全离线**的中文单页 3D 科普展项：用可旋转的实时三维火山模型，讲清火山的**形成**（洋中脊 / 俯冲带 / 热点三种地质环境 → 岩浆部分熔融 → 上升储集 → 喷出堆积）与**影响**（喷发柱、航空、气候、山麓危险、火山的馈赠）。

> 页面中的图形均为**程序化生成的结构示意**，不代表任何一座真实火山的尺度、速度或风险半径，也不提供灾害预测。所有硬数值来自本项目策展简报 TASK-001（2026-10-27 复核），并在界面上逐条标注出处。

---

## 快速开始

```bash
npm ci          # 按锁文件安装（three@0.186.1 / vite@8.3.5）
npm run dev     # 本地开发服务器（127.0.0.1）
npm run build   # 生产构建 → dist/
npm run preview # 预览生产构建
```

一键跑完全部本机检查：

```bash
npm test          # 单元测试（node:test）
npm run check:static  # 静态审计：产物里有无外部运行时请求
npm run smoke     # 用系统 Chrome 通过 CDP 跑真实浏览器验收 + 出截图
```

`npm run smoke` 需要本机已安装 Google Chrome（本机实测 Chrome 156，macOS arm64），不需要额外的浏览器内核下载。

## 工程结构

```
index.html                 静态骨架（可读标题 / 导航 / noscript 兜底）
src/
  main.js                  启动、异常边界、3D 不可用时的降级
  styles/
    tokens.css             ★ 设计令牌唯一真源（全部颜色/间距/圆角/动效都在这里）
    base.css               reset、排版、布局、焦点、断点
    components.css         C01—C11 组件规格与四态
  data/
    facts.js               ★ 事实库：52 条策展事实 + VEI 9 档 + 来源索引
    chapters.js            章节文案与结构（不含任何硬数字）
  state/store.js           同步纯状态机（reducer / dispatch / subscribe）
  scene/
    terrain.js             程序化火山地形（确定性 seeded 噪声）
    crossSection.js        对半剖切面、岩浆房、岩浆通道
    tectonics.js           三类地质环境的板块结构
    effects.js             五种影响场景 + 12 秒喷发序列
    camera.js              相机、视角预设、OrbitControls
    renderer.js            场景装配、状态映射、按需渲染与生命周期
  ui/
    icons.js               统一自绘 SVG 图标
    renderShell.js         语义 DOM 外壳（C01—C11 + 四态）
    controller.js          事件、键盘、hash 路由
    textFallback.js        WebGL 不可用时的静态 SVG 剖面
scripts/
  check-dist.mjs           产物静态审计（外部运行时请求必须为 0）
  serve-dist.mjs           只绑 127.0.0.1 的静态服务器
  smoke-cdp.mjs            用系统 Chrome 跑 CDP 验收
tests/                     node:test 单元测试
reports/                   本机实测报告与截图
```

★ = 唯一真源，改数值只改这两个文件。

## 设计语言

- **颜色**：全部定义在 `src/styles/tokens.css`。23 组前景/背景配对的 WCAG 对比度全部实测达标（正文 ≥ 4.5:1、控件边框 ≥ 3:1、禁用态 ≥ 2:1）。
- **字阶**：以 16px 为基准、1.25 比例的 7 级字阶；中文行长上限 36 字。
- **间距**：4px 基准栅格，只用 `--sp-*` 固定梯度。
- **动效**：只用 `transform` / `opacity`；时长 110 / 180 / 400 / 700ms 四档。
- **图标**：全部为 24×24 网格自绘 inline SVG，线宽 1.75；**不使用 emoji**。

## 来源与限制

- 数值唯一真源：本项目策展简报 `handoff/briefs/TASK-001.md`（2026-10-27 复核）。
- 延伸核验来源（界面上可点开）：USGS 火山形态图鉴、USGS 火山计划 VHP、NASA AURA 汤加观测、NASA 气溶胶教学专题、LAVA Centre。
- **VEI 是爆发威力标尺，不是危害等级**，不能用来预测伤亡或影响范围；界面对此有专门提示。
- 火山碎屑流速度存在 100–200 km/h 与 320 km/h 两种口径，界面按前者呈现并标注差异，**动画速度不代表真实位移**。
- 汤加 2022 的气候效应以**水蒸气**为主，与皮纳图博的**硫酸盐气溶胶**机制不同，界面不把两者降温量相提并论。
- 大塔穆火山「地球最大单体火山」的判定在学界仍有争议，界面只作历史记载呈现，不作确定性排名。
- 航空灰浓度阈值 2 mg/m³ 是**特定评估口径下的工作阈值**，不是「绝对安全线」。
- 图像为程序化科学示意，不提供灾害预测。

---

## 已知限制

- 移动端只做了 375/480px 尺寸仿真，**未在真实低端安卓设备上实测帧率**；软件渲染下会自动降档。
- 喷发动画为 12 秒机制演示，不按真实喷发时长与速度缩放。
- 无后端、无账号、无持久化；页面刷新即回到默认状态（URL hash 会保留展章）。
- 降级版（WebGL 不可用）提供带标注的静态剖面与完整文字，但**不谎称 3D 已就绪**。
